1. System Architecture & Workflow Audit

Deployment Context: Mentorae SIS is built on Express.js and MySQL. The system enforces strict role-based access control (RBAC) across five distinct persona types, automated schedule collision detection, DepEd Order 15 s.2026 grading transmutation, and time-restricted QR turnstile access.

Attendance Rules & Cutoffs
  • Time-In (1st Scan): On/before 07:45 AM = Present; After 07:45 AM = Late.
  • Time-Out (2nd Scan): On/after 15:30 PM = Out; Before 15:30 PM = Excused (Early Leave).
  • 3rd Scan: Returns HTTP 409 Conflict (Already marked out today).
DepEd DO15 s.2026 Grading
  • Transmutation: 70.00% Raw Score = 75.0% Transmuted Passing Grade.
  • Descriptors: ≥90 (Advancing), 80-89 (Benchmarking), 75-79 (Connecting), 65-74 (Developing), <65 (Emerging).
  • Components: Written Works (WW), Performance Tasks (PT), Quarterly Assessment (QA).

2. Role-Based User Task Scenarios

Track A: Administrator Scenarios

Task A-1: New Faculty Onboarding & Smart Student-Parent Enrollment

Goal: Provision a new teacher and enroll a student with automated sibling-parent link resolution.

Starting Point: /user_management_admin.html

Instructions:

  1. Click + Add User / Create Account. Select Role: Teacher, generate ID and email, save.
  2. Re-open modal, select Role: Student, generate sequential ID and email. Enter Name: Juan Dela Cruz, Program: 4Ps, Parent Name: Elena Dela Cruz, Parent Contact: 09175551234, Section: 11 - Newton, submit.

Expected Outcome: User provisioned with temp password equal to ID; Elena Dela Cruz automatically created and linked in parent_student_links without duplicates.

Task A-2: Schedule Creation with Real-Time Conflict Detection

Goal: Schedule a class timetable block and verify collision prevention.

Starting Point: /schedule_management_admin.html

Instructions:

  1. Create schedule for Teacher: Maria Santos, Subject: GENMATH, Section: 11 - Newton, Monday 08:00 - 09:30 AM.
  2. Immediately attempt to schedule Maria Santos for Section 11-Curie on Monday 09:00 - 10:30 AM (overlapping by 30 mins).

Expected Outcome: First schedule writes cleanly (HTTP 201); second schedule is blocked by conflict engine (HTTP 409 Conflict toast alert).

Task A-3: Curriculum Weights Configuration & Emergency Maintenance Drill

Goal: Configure DepEd subject criteria weights and test emergency maintenance mode cutoff.

Starting Point: /subject_management_admin.html & /system_settings_admin.html

Instructions:

  1. On Subject Management, adjust COPRO1 grading weights to WW: 30%, PT: 40%, QA: 30%. Save.
  2. On System Settings, toggle Maintenance Mode to ON. In incognito, attempt to browse teacher or student portal.

Expected Outcome: Teacher/Student requests are intercepted by HTTP 503 and redirected to login.html?reason=maintenance. Admin session remains unrestricted.
